# Атмосферы ZAVIRIA — дизайн-система

Атмосфера — это палитра. Типографика, скругления, отступы и компоненты (`Theme::Plate`, `Island`, `Pick`,
`Widgets::*`) общие для всех. У каждой атмосферы есть светлый и тёмный вариант: они подобраны отдельно, это не инверсия.
Настройка: `[look] atmosphere=0..4`, светлая/тёмная — `[look] mode` (0 тёмная, 1 светлая, 2 как в Windows).

## Токены

| Токен | Роль |
|---|---|
| `top`, `bottom` | фон окна: переход сверху вниз |
| `surface` | островки и панели (с «стеклом» полупрозрачные) |
| `accent` | выбор, главные кнопки, полоски фокуса |
| `ink` | основной текст; `kInkSoft`/`kInkMuted` — та же краска с меньшей непрозрачностью |
| `shadow` | цвет мягкой тени под островками (в светлых вариантах подкрашен в тон) |

## Правила

- Уют создаётся цветом и мягкостью: тёплый молочный фон, кремовые островки, бежевые края, приглушённый коричневый акцент,
  тёплая тень. Без каминов, свечей, дерева и винтажа.
- Переход между атмосферами и между светлой/тёмной — плавный: все токены перетекают за ~0,4 с (`Theme::Apply`), без вспышек.
- Новые компоненты берут цвета только из токенов (`Theme::Surface`, `Accent`, `kInk*`, `Overlay`, `Control`), без своих hex.
